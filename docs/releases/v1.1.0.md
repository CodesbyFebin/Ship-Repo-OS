## ShipOS v1.1.0

The first packaged release brings together the repository auditor, GitHub Workbench, launch assets, and video production tools.

- **GitHub Workbench.** Run 40 evidence checks, assemble a 30-asset launch kit, and use 30 developer utilities. Try the [hosted Workbench](https://codesbyfebin.github.io/Ship-Repo-OS/).
- **Repository audits.** Review missing evidence and ranked fixes. Visibility scores reflect observed repository signals, and generated drafts remain separate from measured results.
- **Demo Maker and Video Studio.** Export a video in the browser’s supported format, cancel without saving a partial file, and download WebVTT captions. The recorder can retry an empty audio capture without music.
- **Developer workflow.** The source includes pinned CI, CodeQL, Node.js matrix checks, and a Docker Compose setup.

The Linux archive requires Node.js 24 and OpenSSL 3. Extract it, run `./start.sh`, and open `http://127.0.0.1:3000`. The launcher initializes SQLite on first run and keeps data in the package’s `data/` directory unless you set `SHIPOS_DATA_DIR`.
